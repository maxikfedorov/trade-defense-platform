Предлагаемая система представляет собой комплексную интеллектуальную платформу поддержки принятия решений для промышленных предприятий в области таможенно-тарифного регулирования, решающую критическую проблему раздробленности производителей и ограниченного доступа к информации о мерах защиты от недобросовестного импорта. Система построена на интеграции трёх взаимодополняющих контуров, обеспечивающих полный цикл от анализа ситуации до генерации готового заявления в Евразийскую экономическую комиссию.

Первый контур — информационно-аналитический — выполняет функцию справочно-оценочного модуля, предоставляя предприятиям актуальную информацию о 8-15 действующих антидемпинговых мерах в ЕАЭС и автоматически анализируя соответствие компании критериям для инициации новых мер. Система принимает от пользователя коды ТН ВЭД товаров, финансовые показатели и описание проблемы с импортом, после чего автоматически рассчитывает долю компании в производстве отрасли на основе данных Росстата и определяет, достигает ли она критического порога в 25% или требуется создание коалиции с другими производителями. Модуль визуализации строит интерактивные дашборды с динамикой импорта, ценами и объёмами, позволяя компании наглядно оценить масштаб проблемы и целесообразность введения защитных мер.

Второй контур — экспертная система на базе RAG-технологии — обеспечивает компаниям доступ к профессиональной юридической экспертизе без необходимости нанимать дорогостоящих консультантов. В основе контура лежит векторная база знаний, содержащая нормативные акты ЕАЭС, методические рекомендации Евразийской экономической комиссии, прецеденты успешного введения 25 защитных мер за всю историю союза и шаблоны официальных документов. Пользователь задаёт вопросы естественным языком — например, "какие доказательства демпинга требует ЕЭК?" или "как доказать причинно-следственную связь между импортом и ущербом?" — и система через комбинацию semantic search на базе ruBERT embeddings и генерации ответов через LLM предоставляет развёрнутые объяснения с обязательными цитатами из первоисточников. Дополнительно модуль анализирует похожие кейсы из истории применения мер, используя ML-классификатор для поиска аналогий, и предоставляет калькулятор прогнозируемой эффективности с оценкой вероятности одобрения заявления регулятором.

Третий контур — коллаборативная платформа — представляет собой ключевую инновацию системы, решающую фундаментальную проблему невозможности отдельных производителей достичь критического порога в 25% производства отрасли. Платформа функционирует как прозрачная площадка для создания и координации "кампаний" по введению защитных мер: крупный производитель инициирует кампанию, указывая проблемные коды ТН ВЭД и описание ситуации, после чего другие производители аналогичных товаров могут обнаружить эту кампанию и присоединиться к ней, указав свою долю на рынке. Система автоматически валидирует заявленные доли через данные Росстата и отображает визуальный прогресс-бар достижения порога 25%, отправляя уведомления всем участникам о новых присоединениях. После формирования коалиции участники переходят к структурированному сбору доказательной базы через три специализированные вкладки: первая собирает доказательства факта демпинга через загрузку таможенной статистики и сравнение цен, вторая аккумулирует доказательства материального ущерба через финансовую отчётность и данные о загрузке мощностей, третья формирует аргументацию причинно-следственной связи между демпингом и ущербом. На финальном этапе LLM-генератор автоматически заполняет официальные шаблоны приложений №1 и №2 к заявлению в ЕЭК, используя собранные структурированные данные и подставляя юридически корректные формулировки с цитатами из нормативных актов ЕАЭС через RAG-систему, создавая готовый пакет документов для подачи регулятору через API или экспорта в формате docx/pdf.

Архитектура системы реализована как веб-платформа с единым API-шлюзом, обслуживающим React-интерфейс и потенциальный телеграм-бот, с центральным оркестратором на FastAPI, управляющим состояниями диалога и координацией между модулями, PostgreSQL для хранения данных о пользователях, компаниях и кампаниях, и специализированными ИИ-компонентами. Искусственный интеллект применяется точечно на семи критических этапах: ML-классификатор определяет подходящий тип меры на основе описания проблемы компании; WebSearch-агент мониторит обновления на сайтах ФТС, ЕЭК и Минэкономразвития для актуализации справочной информации; RAG-движок на базе Qdrant векторной базы с ruBERT embeddings обеспечивает семантический поиск по нормативной базе для ответов на вопросы пользователей с обязательными цитатами; модуль визуализации автоматически парсит и строит графики корреляции между динамикой импорта и падением продаж для наглядной демонстрации причинно-следственной связи; ML-поиск идентифицирует похожие кейсы из 25 исторически введённых мер для предоставления пользователям примеров успешной аргументации; LLM-генератор на базе GigaChat или YandexGPT формирует юридически грамотные тексты доказательства связи между демпингом и ущербом на основе загруженных пользователями структурированных данных; и на финальном этапе комбинация LLM с RAG создаёт заполненное заявление в ЕЭК, используя structured generation для точного заполнения полей шаблонов приложений №1 и №2 и автоматически подставляя ссылки на релевантные статьи законодательства ЕАЭС.
