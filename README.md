Предлагаемая система представляет собой **автоматизированную информационную систему для системной оценки целесообразности применения мер таможенно-тарифного регулирования**, решающую критическую проблему отсутствия у промышленных предприятий доступа к комплексному аналитическому инструменту, способному на основе объективных данных мировой таможенной статистики и производственных показателей России определить оптимальные меры защиты рынка для конкретного товара. Система реализована как веб-платформа с минимальным пользовательским интерфейсом, где предприятие вводит единственный параметр — действующий код ТН ВЭД товара на шесть или десять знаков — после чего система автоматически проводит внутренние вычисления на основании данных из международных и российских источников и без выдачи пользователю первичных массивов данных таможенной статистики предоставляет структурированный перечень из одной или нескольких мер ТТР, целесообразных к применению в конкретной ситуации, с указанием типа меры, охвата стран и конкретных значений ключевых показателей.

**Второй слой — движок принятия решений на основе правил** — представляет собой rule-based систему, реализующую шесть параллельных алгоритмов оценки целесообразности различных типов мер таможенно-тарифного регулирования. При получении запроса с кодом ТН ВЭД система одновременно применяет все шесть наборов критериев и формирует список рекомендованных мер, причём одновременно может быть выдано несколько мер, если товар соответствует критериям для нескольких типов защиты. Алгоритмика идёт согласно пути эксперта.

**Третий слой — презентация результатов с использованием технологий искусственного интеллекта** — обеспечивает пользователю доступ к структурированной информации и экспертным консультациям. После завершения вычислений система выдаёт результат в формате структурированной карточки для каждой рекомендованной меры, содержащей: тип меры из перечня шести возможных вариантов; географический охват с указанием конкретных стран или групп стран, в отношении которых будет действовать мера; набор специфических показателей, релевантных для данной меры — текущая и целевая ставка пошлины, доля импорта из недружественных стран в процентах, темп изменения импорта, среднеконтрактные цены по странам происхождения, соотношение производства к потреблению — при этом первичные массивы таможенной статистики пользователю не предоставляются в соответствии с требованиями конфиденциальности и фокусировки на выводах, а не на сырых данных. Для повышения понятности выводов система использует **модуль генерации текстовых обоснований на базе большой языковой модели**, который автоматически формирует связное описание логики рекомендации: "Система рекомендует повышение ставки таможенной пошлины до уровня связывания в ВТО с 5% до 10%, так как доля импорта из недружественных стран составляет 22% и снизилась на 5 процентных пунктов по сравнению с аналогичным периодом прошлого года, при этом российское производство составляет 115% от внутреннего потребления, что обеспечивает защиту от дефицита при введении меры". Дополнительно система интегрирует **RAG-модуль для консультационной поддержки**, позволяющий предприятию задавать вопросы естественным языком о процедуре реализации рекомендованных мер — например, "Какие документы нужны для инициирования антидемпингового расследования?" или "Как долго рассматривается заявление о повышении пошлины?" — и получать развёрнутые ответы с цитатами из нормативных актов и методических рекомендаций ЕЭК, федеральных органов исполнительной власти и Правительства РФ, извлечённые из векторной базы знаний через семантический поиск на основе ruBERT embeddings. Модуль визуализации автоматически строит интерактивные графики и диаграммы, иллюстрирующие ключевые тренды — динамику импорта из различных стран за последние годы, сравнение контрактных цен между странами-экспортёрами, соотношение производства и потребления во времени — предоставляя предприятию наглядное подтверждение обоснованности рекомендаций без доступа к первичным таблицам статистики.

**Сценарий использования системы** реализован в пять последовательных шагов, обеспечивающих полный цикл от запроса до подготовки документов для федеральных органов. На первом шаге предприятие создаёт в системе запрос, вводя действующий код ТН ВЭД товара на шести или десяти знаках, опционально добавляя текстовое наименование для собственного удобства идентификации товара в будущих обращениях. На втором шаге система автоматически проводит внутренние вычисления, применяя все шесть алгоритмов оценки к данным, собранным из международных и российских источников, и без выдачи пользователю первичных массивов таможенной статистики формирует структурированный ответ, содержащий один или несколько типов мер с обоснованием и конкретными параметрами. На третьем шаге предприятие, используя полученную информацию из системы, формирует официальное обращение в АНО "Моспром" с приложением скриншотов или экспортированного отчёта из ЕАИС, содержащего базовую аналитику по рекомендованным мерам, что существенно облегчает работу эксперта на стороне организации по предварительной оценке обоснованности инициативы без необходимости самостоятельно собирать и анализировать разрозненную статистику. На четвёртом шаге эксперт АНО "Моспром" использует ту же систему для независимой проверки корректности представленных сведений, вводя аналогичный код ТН ВЭД и сопоставляя результаты с заявлением предприятия, после чего на основании экспертного заключения по представленной инициативе начинает совместную с компанией работу по формированию полного пакета документов для передачи в ответственные федеральные органы исполнительной власти. На пятом финальном шаге АНО "Моспром" совместно с предприятием направляют подготовленный пакет документов с обязательным приложением данных и аналитических выводов, полученных по результатам использования системы, на рассмотрение ответственных ФОИВ, при этом наличие объективной аналитики из автоматизированной системы существенно повышает доверие регулятора к обоснованности инициативы и ускоряет процесс принятия решения о целесообразности введения запрашиваемой меры.

**Технологическая реализация системы** основана на модульной архитектуре с использованием современных инструментов интеграции, обработки данных и искусственного интеллекта. Фронтенд реализован на фреймворке React с минималистичным интерфейсом, где центральным элементом является поисковая строка для ввода кода ТН ВЭД и область отображения результатов в виде структурированных карточек мер с возможностью развёртывания детальной информации и экспорта отчётов в форматах PDF и Excel для приложения к официальным обращениям. Бэкенд построен на Python-фреймворке FastAPI, обеспечивающем высокую производительность обработки запросов и простоту интеграции с внешними API, с MongoDB в качестве основной базы данных.  Rule-based движок принятия решений реализован через декларативный подход с использованием библиотеки Business Rules Engine, где каждая мера представлена набором условий в формате конфигураций, что позволяет экспертам АНО "Моспром" модифицировать критерии оценки без изменения программного кода при корректировке методологии или изменении нормативных требований. **Искусственный интеллект применяется точечно** в трёх критических точках системы: модуль генерации текстовых обоснований использует API большой языковой модели GigaChat или YandexGPT с низкой температурой генерации для создания связных объяснений логики рекомендаций на основе структурированных выходных данных rule-based движка с обязательным указанием конкретных числовых значений показателей; RAG-система для консультационной поддержки реализована на базе векторной базы данных с embeddings, созданными через deepvk/user-bge модель, индексирующей корпус нормативных актов, методических рекомендаций и процедурных инструкций, с LLM-генератором ответов, который обязательно включает цитаты из источников для обеспечения юридической корректности консультаций.

**Система решает обе проблемы, указанные в постановке кейса**: основная проблема недоступности и непонятности инструментов аналитики для сотрудников промышленных предприятий устраняется через максимально упрощённый интерфейс с единственным обязательным полем ввода и автоматизированные вычисления на основе объективных данных, которые не требуют от пользователя экспертизы в таможенном регулировании или статистическом анализе; второстепенная проблема неполных или нерелевантных инициативных предложений от предприятий к органам исполнительной власти решается через стандартизацию формата обращений, где каждое предложение автоматически сопровождается структурированной аналитикой из ЕАИС с конкретными типами рекомендованных мер, целевыми странами и численными значениями ключевых показателей, что позволяет экспертам АНО "Моспром" и федеральных органов быстро оценить обоснованность инициативы и сфокусироваться на подготовке документации для реализации меры вместо первичного анализа целесообразности. Масштаб внедрения системы охватывает АНО "Моспром" в качестве первичного пользователя для проверки инициатив от промышленных предприятий и непосредственно промышленные предприятия Москвы в качестве конечных пользователей для самостоятельной оценки целесообразности мер таможенно-тарифного регулирования перед формированием официальных обращений, при этом архитектура системы допускает масштабирование на уровень всей России или интеграцию с федеральными информационными системами при успешной апробации в столичном регионе.
