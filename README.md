# Система оценки мер таможенно-тарифного регулирования

Интеллектуальная аналитическая система для оценки эффективности и подбора мер таможенно-тарифного регулирования (ТТР) для промышленных предприятий.

## О проекте

**Trade Defense Platform** — это прототип интеллектуальной аналитической системы, разработанный в рамках хакатона «Открой#Моспром».

### Проблема

Промышленные предприятия сталкиваются со сложностями при оценке целесообразности введения мер таможенно-тарифного регулирования (ТТР) из-за разрозненности данных и сложности аналитических инструментов. Это затрудняет защиту внутреннего рынка и формирование обоснованных инициатив для органов исполнительной власти.

### Решение

Система автоматизирует анализ данных и по запросу пользователя (код ТН ВЭД) предоставляет перечень релевантных мер ТТР. Это позволяет предприятиям оперативно получать аналитическую справку для защиты своих интересов и упрощает взаимодействие с государственными структурами.

## Логика работы

Система анализирует запрос пользователя на основе кода ТН ВЭД и предлагает одну или несколько мер ТТР, основываясь на встроенных критериях.

#### Возможные рекомендации системы:

* **Повышение ставки пошлины до уровня ВТО:** Применяется, если текущая ставка ниже обязательств в ВТО, а импорт из недружественных стран незначителен и снижается.
* **Повышение ставки пошлины (контрсанкции):** Рекомендуется при стабильном или растущем импорте из недружественных стран, составляющем более 30% рынка.
* **Антидемпинговое расследование:** Инициируется при росте демпингового импорта, который наносит ущерб отечественному производству.
* **Преференциальный режим в госзакупках:** Предлагается для товаров, включенных в соответствующие постановления Правительства РФ.
* **Введение обязательной сертификации:** Применяется для товаров, где растущий импорт можно ограничить требованием подтверждения соответствия.
* **Иные меры защиты (квоты, запреты):** Рекомендуются в крайних случаях, когда импорт значительно превышает внутреннее производство, а другие меры нецелесообразны.

## Установка и запуск

Для развертывания проекта необходимо иметь установленные Docker, Node.js (v22.18.0+) и Python.

1. **Клонировать репозиторий:**

   ```
   git clone https://github.com/maxikfedorov/trade-defense-platform.git
   cd trade-defense-platform
   ```
2. **Запуск с помощью Docker Compose (рекомендуемый способ):**

   ```
   docker-compose up --build
   ```

   Приложение будет доступно по адресу `http://localhost:5173`.
3. **Локальный запуск (для разработки):**

   * **Backend Gateway:**
     ```
     cd backend-gateway
     # Укажите конфигурацию в application.properties
     ./gradlew bootRun
     ```
   * **AI Backend:**
     ```
     cd ai-backend
     pip install -r requirements.txt
     uvicorn main:app --reload
     ```
   * **Frontend:**
     ```
     cd frontend
     npm install
     npm run dev
     ```
